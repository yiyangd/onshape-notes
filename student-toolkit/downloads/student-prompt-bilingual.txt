How to build and document the project
【请这样操作并交付】
1. Read my course materials, then look at my open Onshape document. Check the feature list, the geometry already in place, the units, and the expected finished shape. Continue from my starting point. Label any dimension you choose because the materials leave it unspecified as a “suggested practice value.” If you are unsure which file to edit, ask me to identify it first.
1. 先读课件，再看我当前打开的 Onshape，确认特征树、已有几何、单位和目标成品。从我的起点继续。课件没给的尺寸如需自定，请标为“练习建议值”。分不清应改哪个文件时，先问我具体文件。

2. Build the model in Onshape and capture the screen as you work. You can also use excerpts from my own recording. For each step, state the goal first. Then say whether to click, double-click, or right-click. Give the English name of the button or menu, the exact face, edge, point, or field to select, where to start and end any drag, what number and unit to enter, which key confirms it, and what should appear. For example, when selecting the Origin on the canvas as the apex, zoom in on the bullseye and the tip of the pointer. Then show the new “Vertex of Origin” entry in Profiles. Choose checks that fit this project.
2. 请实际操作建模，并在操作时捕捉真实画面；也可以剪我提供的真实录屏。每个步骤写清鼠标单击、双击还是右击，按钮或菜单的英文名，应该点哪个面、边、点或输入框，拖动从哪里到哪里，输入哪个数和单位，按什么键确认，以及做对后看到什么。先说目标再说点击位置。例如，选画布上的 Origin 作锥顶时，放大靶心和鼠标落点，并展示 Profiles 新出现的 Vertex of Origin。按项目需要选择相应的检查点。

3. Make a looping GIF of about 1–2 seconds for each step. Show the target, the click, and the result. Split a long series of clicks into smaller steps. Enlarge the relevant area of the actual recording when the target is easy to miss. Label a step with only a still image “Screenshot demonstration.” If a click is missing, record it again when possible. If footage is still missing, keep the step number in both Word and the website and mark it “Recording needed.” Tell me what should be on screen at the start, where to click, and what result to capture. If an error appears, explain how to recognize and fix it. If you cannot control the browser, use my recording to complete the steps you can verify.
3. 每步做一个约 1–2 秒的循环 GIF，让学生看清“目标 → 点击 → 结果”。动作太多就拆开，容易点错的位置用真实画面局部放大。仅有截图的步骤标为“截图示范”。如果漏了一次点击，能补录就补录；缺少画面时，在 Word 和网页保留其编号并标“待补录”，告诉我要从哪个画面开始、点什么、录到哪个结果。遇到报错，解释怎样识别和修复。如果暂时无法控制浏览器，先用我的录屏完成能核实的部分。

4. Create an editable bilingual Word document (.docx). For each step, put the English instructions first and the Chinese translation immediately below. Keep the English button names used in Onshape. Embed the matching GIF below the instructions, followed by one sentence describing what I should see when the step works. Keep the step numbers, values, and units consistent.
4. 生成一份可编辑的双语 Word（.docx）：每步先英文、下方紧跟中文，保留 Onshape 界面的英文按钮名。把对应 GIF 嵌在这一步下面，紧接一句“成功时看到什么”。步骤号、数字和单位前后一致。

5. Build a static site with a project directory at index.html. Give each project its own tutorial page (e.g., pyramid/index.html), a link back to the directory, and links to individual steps such as #step-09. On a first visit, the home page and every tutorial must show English only. Put a “Bilingual · 双语” button on each page. One click shows Chinese directly below each English title, label, caption, and step instruction. Click again to hide the translations. Remember the choice across pages and after a refresh. When adding a lesson to an existing site, reuse its language button and saved preference.
5. 生成静态网站，首页 index.html 显示项目目录。每个项目都有独立教程页（如 pyramid/index.html）、返回目录的链接，以及 #step-09 这样的步骤直达链接。首次访问首页或任何教程页时，默认只显示英文。每页都放一个「Bilingual · 双语」按钮。点一次，在每个英文标题、标签、图注和步骤说明的正下方显示对应中文。再点一次收起译文。切换页面或刷新后，记住学生的选择。 给已有网站添加新课时，沿用该站的语言按钮和保存的语言设置。

Place a playable GIF below each step and let students open it at full size. Match the step numbers and demonstrations in Word. In English mode, use GIFs and diagrams with English labels or no text. If a visual has Chinese labels built in, switch both the embedded image and its full-size link to the version for the selected language.
每步说明下方放一张可以循环播放、单独打开放大的 GIF，步骤号和演示内容与 Word 对应。英文模式使用英文标注或无文字的 GIF 和示意图。如果中文标签已经嵌入画面，切换语言时让页内配图和原图链接一起切到对应语言的版本。

6. Package the editable Word guide, website, and GIFs together. After extraction, double-clicking index.html must open the site offline. Keep the English instructions readable even when JavaScript is off. Crop account details and private document addresses out of shared media. On desktop and mobile, test a fresh visit, switch both ways, open a project, return home, and refresh. Test the button with the keyboard, play a GIF, open it full size, and check the Word layout. Publish only if I specify a destination. Keep the existing lessons and upload only public-facing site files to that repository. After deployment, click a project from the public home page, confirm its own path (e.g., /pyramid/), and send me the link you tested.
6. 把可编辑的 Word、网站和 GIF 放进同一份本地教学包。解压后，双击 index.html 就能离线打开，即使关闭 JavaScript 也能阅读英文说明。裁去共享素材里的账号和私人文档地址。在电脑和手机上模拟首次访问，来回切换语言，打开项目、返回首页并刷新。再用键盘操作按钮，检查 GIF 的播放和原图链接，以及 Word 排版。仅当我指定目标时，才把网页和适合公开的素材发布到该仓库，保留已有课程。发布后，从公开首页点击项目，核对地址栏进入项目自己的路径（例如 /pyramid/），把实测可打开的链接发给我。
