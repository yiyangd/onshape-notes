直接使用提示词

  1. 用 Codex 打开一个作业文件夹，附上老师给的 PDF、PPT 或自己的录屏。
  2. 在浏览器中登录自己的 Onshape，打开练习用的文档和 Part Studio。现场演示时，让 Codex 连接到这个浏览器。
  3. 复制下方全文，粘贴到 Codex 对话框。先填写项目名称和参考材料，再写明当前进度、操作位置和发布方式，然后发送。

在项目中使用 Skill

把这套流程保存到自己的作业项目，下次换一个模型，只需在对话里写出 Skill 名称。

下载 Skill（ZIP）

  1. 解压下载的 ZIP，找到含有 SKILL.md 的 onshape-project-tutor 文件夹。
  2. 把这个文件夹放进作业项目的 .agents/skills/。如果目录还没有，可以先创建。放好后的文件路径应为 .agents/skills/onshape-project-tutor/SKILL.md。
  3. 用 Codex 打开作业项目，附上课件，输入下面这句话，并换成自己的进度。

请用 $onshape-project-tutor 做我附上的 Onshape 作业。我已经画好正方形底面，请从 Loft 开始，做成中英双语 Word 和逐步 GIF 网站。这次只做本地包。

从新文件夹开始

完整工具包里有使用说明、提示词和已放好位置的 Skill。把整包解压到新的作业文件夹，再用 Codex 打开即可。
