Use the prompt直接使用提示词

  1. Open your assignment folder in Codex. Attach your teacher’s slides, a PDF, or your own screen recording.用 Codex 打开作业文件夹，附上老师给的课件、PDF 或自己的录屏。
  2. Sign in to Onshape and open the document and Part Studio you want to use. For a live demonstration, connect Codex to that browser.登录 Onshape，打开要使用的文档和 Part Studio。如需现场演示，请让 Codex 连接到这个浏览器。
  3. Copy the prompt below into Codex. Fill in the five fields with your project name, reference material, starting point, workspace, and publishing preference. Then send it.把下面的提示词复制到 Codex。填写项目名称、参考材料、当前进度、操作位置和发布方式，再发送。

Use the Codex skill在项目中使用 Skill

Add the skill to an existing project so you can call it by name when you start another model.把 Skill 加入已有的项目，之后换一个模型时，就可以直接按名称调用。

Download skill (.zip)下载 Skill（ZIP）

  1. Unzip the file and find the onshape-project-tutor folder that contains SKILL.md.解压文件，找到包含 SKILL.md 的 onshape-project-tutor 文件夹。
  2. Place that folder inside .agents/skills/ in your project. Create those folders if needed. Check that the file is at .agents/skills/onshape-project-tutor/SKILL.md.把整个文件夹放入项目的 .agents/skills/ 中。如果目录还没有，可以先创建。确认文件路径是 .agents/skills/onshape-project-tutor/SKILL.md。
  3. Open the project in Codex and attach your lesson materials. Adapt this example to your starting point.在 Codex 中打开项目并附上课件。把下面示例中的起点换成自己的实际进度。

Use $onshape-project-tutor for my attached Onshape assignment. My square base is ready. Start with Loft and make a bilingual Word guide and a GIF tutorial website. Create a local package only.请用 $onshape-project-tutor 做我附上的 Onshape 作业。我已经画好正方形底面，请从 Loft 开始，做成双语 Word 和逐步 GIF 网站。这次只做本地包。
